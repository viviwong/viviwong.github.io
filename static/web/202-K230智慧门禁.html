💡 架构核心F407 是三串口路由中枢：USART1（115200）连 PC 上位机做考勤与日志、USART2（9600）连 DX-BT24 蓝牙模块与小程序双向透传、USART3（115200）接收 K210 人脸识别帧。人脸事件同时分发到本地效果（LED/蜂鸣器）、HMI（10 秒在场打卡）和小程序（考勤页实时刷新），三端状态一致。

功能模块功能细节

📡 串口通信协议设计（固件 v2.0 实测协议）

⬇️ 下行指令
（小程序 → BLE → F407）
CMD:<操作>\r\n
⬆️ 温湿度上报
（F407 → BLE → 小程序，每 5s）
DATA:TEMP:26.0:HUM:58.0\r\n
🧠 人脸结果
（K210 → F407 → HMI / 小程序）
FACE:<name>:<score>\r\n
帧示例含义方向
CMD:LED_ALL_ONLED 全部常亮（LED_MODE_ON）小程序 → F407
CMD:LED_ALL_OFFLED 全部关灭（LED_MODE_OFF）小程序 → F407
CMD:MODE_BREATH呼吸灯模式（上电默认 / 下班模式）小程序 → F407
CMD:MODE_FLOW流水灯模式小程序 → F407
CMD:MODE_RUNNING跑马灯模式小程序 → F407
CMD:MODE_FLASH爆闪模式小程序 → F407
CMD:BEEP蜂鸣器短鸣 200ms小程序 → F407
DATA:TEMP:26.0:HUM:58.0温湿度上报，上电立即一次 + 每 5s 一次F407 → 小程序
FACE:person0:96.8已注册人脸识别成功（face_index=0），LED 常亮 3sK210 → F407 → HMI/小程序
FACE:unknown:0.0陌生人，爆闪 + 蜂鸣 3s，HMI/小程序标红报警K210 → F407 → HMI/小程序
REG:person0K210 注册成功帧，F407 本地打印（不透传 BLE），HMI 更新注册状态K210 → F407 → HMI
⚠️ 协议要点所有帧以 \r\n 结束、接收端以 \n 为分帧符。F407 端用 256B 环形缓冲（ISR 写、BLE_Poll() 主循环组帧）防丢帧；小程序端用 _rxBuf 拼接处理 BLE 粘包；收到任意 CMD:* 会清除 K210 触发的 LED 效果锁。这三处是联调时最常见的坑，课上重点讲。

外设用途关键参数
