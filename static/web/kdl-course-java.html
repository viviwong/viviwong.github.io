Curriculum

系统化 6 阶学习路线

从零到全栈 AI 工程师，每个阶段都有完整的项目实战与技能验收。

Stage 01
Java 基础与面向对象
夯实 Java 语法基础，深入理解面向对象设计原则，掌握集合、泛型、异常处理、IO 流，具备独立编写 Java 程序的能力。
Java基础语法OOP集合框架多线程IO/网络
Stage 02
前端开发 Vue3 全栈
从 HTML/CSS/JS 基础到 Vue3 组件化开发，掌握 Axios、Pinia 状态管理、ElementPlus UI 框架，独立完成前端工程。
HTML/CSSVue3PiniaAxiosElementPlus
Stage 03
Spring 全家桶后端开发
深入 Spring Boot、Spring MVC、MyBatis-Plus，掌握 RESTful API 设计、拦截器、JWT 鉴权，构建规范的企业级后端服务。
Spring BootSpring MVCMyBatis-PlusRESTful APIJWT
Stage 04
数据库与缓存中间件
掌握 MySQL 高级查询优化、事务与锁机制，深入 Redis 缓存设计、消息队列应用，具备高并发系统的数据层设计能力。
MySQL进阶RedisRabbitMQ索引优化分库分表
Stage 05
AI 智能体与大模型开发
学习 LangChain4j、RAG 检索增强生成、Function Calling，使用 Java 构建 AI 智能体应用，将大模型能力集成到企业系统中。
LangChain4jRAGAI Agent向量数据库提示词工程
Stage 06
微服务架构与毕业项目
深入 Spring Cloud 微服务、Nacos 注册中心、Gateway 网关，完成一个完整的全栈 AI 项目，形成可展示的作品集。
Spring CloudNacosGatewayDocker综合项目
