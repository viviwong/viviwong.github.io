Curriculum

系统化 6 阶学习路线

从零基础到可独立承担嵌入式 AI 项目，每个阶段目标清晰、项目驱动。

Stage 01
C 语言与数据结构
从底层思维出发，掌握内存管理、指针、结构体，为后续所有开发打下坚实基础。同步学习 Linux 基础操作与 Shell 脚本。
C语言基础指针与内存数据结构Linux基础Shell脚本
Stage 02
嵌入式 Linux 系统编程
深入 Linux 内核机制，掌握进程/线程、文件I/O、网络编程、IPC进程间通信，能独立开发 Linux 应用层程序。
进程与线程文件IO网络编程IPC通信Makefile
Stage 03
MCU 与 RTOS 实时系统
基于 STM32 进行外设编程，掌握 FreeRTOS 任务调度、信号量、消息队列，开发具备实时响应能力的嵌入式产品。
STM32HAL库FreeRTOSGPIO/UART/SPI外设驱动
Stage 04
Linux 驱动开发
深入内核空间，掌握字符设备驱动、总线驱动模型（SPI/I2C/USB），编写 Device Tree，理解完整驱动框架。
字符设备驱动I2C/SPI驱动设备树内核模块驱动框架
Stage 05
AI 视觉与边缘推理
学习 OpenCV 图像处理、YOLO 目标检测，在嵌入式平台（RK3588/Jetson）上部署 AI 模型，掌握边缘 AI 推理全流程。
OpenCVYOLO模型量化RK3588ONNX Runtime
Stage 06
大模型接入与毕业项目
将 LLM API 接入嵌入式系统，完成一个完整的 AIoT 综合项目（如智能巡检机器人 / 工业视觉质检系统），形成可展示的作品集。
LLM APIAI AgentMQTT/边缘云综合项目作品集
Career Paths

毕业后的 6 条职业路径

嵌入式 AI 工程师的出口极为多元，覆盖从智能硬件到工业 AI 的广泛就业市场。

⚙️
嵌入式软件工程师
12K–22K
负责嵌入式产品的应用层和驱动层开发，覆盖消费电子、工业控制等行业。
🐧
Linux 驱动工程师
15K–30K
专注内核驱动开发，为硬件提供软件接口，是芯片厂商和设备制造商的核心岗位。

AIoT 开发工程师
14K–25K
负责物联网设备的端云架构设计，集成 AI 能力，推动传统设备智能化升级。
⏱️
RTOS 固件工程师
12K–20K
基于实时操作系统开发高可靠性固件，广泛应用于汽车电子、工业自动化领域。
👁️
AI 视觉工程师
18K–35K
负责在嵌入式平台部署视觉 AI 算法，是机器人和工业质检领域的高薪核心岗位。
🔬
硬件 AI 算法工程师
20K–40K
深度融合算法与硬件，负责模型部署优化和边缘推理加速，是稀缺高端岗位。
