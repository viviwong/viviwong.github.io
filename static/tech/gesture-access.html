手势识别与串口使用说明

本页面在浏览器本地处理摄像头画面，识别结果可通过 USB 串口发送到开发板。

  1. 使用桌面版 Chrome 或 Edge 打开页面，localhost 或 HTTPS 下点击“启动摄像头”并允许访问。
  2. 点击“选择并连接”，选择开发板对应的 USB 串口，并设置与固件一致的波特率。
  3. 张开手掌会发送 OPEN\n，握拳会发送 CLOSE\n；手动按钮还可发送 STOP\n。
  4. 数据格式为 ASCII 文本加换行符。请让单片机按行接收，并按设备协议调整命令映射。

串口连接后可在日志中查看 TX 发送和 RX 接收内容。连续相同手势有发送间隔限制，可先用手动按钮检查串口通信。
