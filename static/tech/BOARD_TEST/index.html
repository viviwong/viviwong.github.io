KDL / QUICK START

功能说明

  1. 接入开发板 UART1，在桌面版 Chrome 或 Edge 中通过 HTTPS 或 localhost 打开页面，点击「连接开发板」。串口参数为 115200、8N1。
  2. 连接后，页面显示温湿度和光照。按下 K1～K4 时对应指示会短暂点亮。音乐播放期间固件只接收停止音乐指令。
  3. 模块测试和一键自检的状态来自固件反馈。当前固件暂未实现 MIC 收音测试，SD 卡项目检测初始化，SPI 项目读取芯片 ID。
  4. 按接线图连接 ESP8266 和舵机。先配置 Wi-Fi，再输入物联网 TCP 服务器的 IPv4 和端口。Wi-Fi 密码仅用于向开发板发送配置。
