QUICK START / 使用指南

功能说明

  1. 用 USB 转串口连接设备。在桌面 Chrome 或 Edge 打开页面，点击「连接串口」并选择对应设备。在线访问需使用 HTTPS，本地调试可用 localhost。
  2. 连接后自动查询设备状态。距离随固件上报更新，显示「无回波」时表示此次测距无效。
  3. 可开盖、关盖、查询状态、清除报警和切换灯效。满桶时固件会拒绝开盖，请先清空垃圾，再清除报警。
  4. 手动发送可输入指令，页面自动补上句点。串口记录可导出为文本文件，最多保留最近 500 条。
