## 📚 五大实训方向

### 1. 🤖 嵌入式 AI 实训

> **方向定位：** 硬件 × 人工智能，打造会「感知 + 思考」的智能设备

**核心技术栈：**
- 主控芯片：STM32F4 系列（ARM Cortex-M4）
- 传感器：温湿度（DHT11）、光照、超声波、摄像头等
- 通信协议：UART、I²C、SPI、蓝牙 BLE、MQTT over Wi-Fi
- AI 能力：目标检测（YOLO lite）、语音识别、边缘推理部署
- 上位机联动：微信小程序 / App 实时数据可视化

**典型项目：**
- 🌡️ IoT 温湿度远程监控系统（STM32 + BLE + 小程序）
- 🚗 智能小车避障 + 视觉循迹
- 🏠 智能家居控制面板（语音 + App 双控）
- 👁️ 边缘端目标检测摄像头

**适合人群：** 电子/电气/计算机专业，有 C 语言基础

---

### 2. ✨ Vibe Coding 实训

> **方向定位：** AI 辅助编程新范式，用自然语言驱动代码生成，效率提升 10×

**核心技术栈：**
- AI 编程工具：GitHub Copilot、Cursor、WorkBuddy、通义灵码
- 大模型接入：OpenAI GPT-4o、DeepSeek、Claude、讯飞星火
- 工程化：Prompt Engineering、AI Agent 工作流搭建
- 全栈落地：前端（React/Vue）+ 后端（Node/FastAPI）+ 数据库

**典型项目：**
- 💬 AI 对话应用（接入主流大模型，支持多轮对话）
- 📊 AI 数据分析助手（自然语言查询 → 图表生成）
- 🛠️ AI 代码审查机器人（自动 Review + 修复建议）
- 🤖 个人 AI 助手（记忆 + 工具调用 + 知识库）

**适合人群：** 所有方向均可，是「效率倍增器」，建议全员学习

---

### 3. 📱 微信小程序实训

> **方向定位：** 国内用户量最大的轻应用平台，零门槛触达 10 亿微信用户

**核心技术栈：**
- 基础框架：WXML + WXSS + JavaScript（原生小程序）
- 进阶框架：微信云开发（CloudBase）
- 组件库：Vant Weapp、TDesign Mobile
- 后端对接：RESTful API、WebSocket 实时通信
- 能力扩展：蓝牙 BLE、地图、支付、订阅消息

**典型项目：**
- 🤖 AI 生活助手（接入 DeepSeek，新闻/笑话/星座/AI 对话）
- 🌡️ IoT 数据采集监控平台（配合嵌入式方向联动）
- 🛒 电商小程序（商品列表、购物车、下单支付全流程）
- 📅 校园服务助手（课表查询、快递代取、失物招领）

**适合人群：** 前端/全栈开发方向，有 HTML/CSS/JS 基础优先

---

### 4. 📲 APP 开发实训（UniApp）

> **方向定位：** 一套代码，同时发布 iOS / Android / 小程序 / H5，开发效率最大化

**核心技术栈：**
- 框架：UniApp（基于 Vue 3）
- UI 组件库：uni-ui、uView Plus
- 状态管理：Pinia
- 网络请求：uni.request / axios
- 原生能力：相机、定位、推送通知、本地存储
- 打包发布：HBuilderX 云打包，支持 Android APK / iOS IPA

**典型项目：**
- 🏋️ 运动健身 App（运动记录、计划制定、数据图表）
- 🍱 点餐外卖 App（门店列表、菜单点餐、订单追踪）
- 📚 在线教育 App（课程购买、视频播放、学习打卡）
- 🗺️ 旅游攻略 App（景点地图、路线规划、游记分享）

**适合人群：** 移动端开发方向，有 Vue 基础更佳

---

### 5. 🎨 UI 全链路设计实训

> **方向定位：** 从需求分析到交付走查，掌握产品设计完整工作流，做出让开发「一眼爱上」的设计稿

**核心技术栈：**
- 设计工具：Figma（主）/ MasterGo / 即时设计
- 原型工具：Axure RP / Figma 原型模式
- 设计规范：Material Design 3、Apple HIG、微信小程序设计规范
- 切图交付：Figma Dev Mode、蓝湖标注
- AI 设计提效：Midjourney、Stable Diffusion、Adobe Firefly

**学习路径：**

```
需求分析 → 用户调研 → 信息架构 → 低保真线框图
    ↓
视觉设计 → 组件库搭建 → 高保真 UI 稿 → 动效原型
    ↓
设计规范文档 → 开发标注切图 → 走查验收 → 迭代优化
```

**典型项目：**
- 📱 电商 App UI 全套设计（从品牌到交互完整输出）
- 🌐 企业官网改版（响应式布局 + 品牌升级）
- 🖥️ SaaS 管理后台设计系统（含组件库 100+）
- 🎮 游戏类小程序界面设计

**适合人群：** 设计方向，有一定审美基础，热爱创造视觉产品
