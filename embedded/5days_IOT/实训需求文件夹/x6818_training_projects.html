5个AI实训方向
01

AI 工业质检上位机

用摄像头 + YOLO 检测产品缺陷，PySide6 实时显示结果

学生在电脑端用 YOLOv8 训练缺陷模型，导出 ONNX 后部署到开发板，PySide6 界面实时拉取摄像头画面并标注检测框，输出 OK/NG 判决和统计报表。完全对标工厂视觉质检岗位。

AI 在哪：PC 端训练 YOLOv8 → 开发板推理（OpenCV DNN + ONNX），双端均有 AI
YOLOv8 / ONNX OpenCV PySide6 MIPI 摄像头 工业视觉
02

智能工厂环境监控 + AI 异常预警

传感器数据 → MQTT → PySide6 大屏 → AI 预测报警

开发板采集温湿度、气体、振动等传感器数据，通过 MQTT 上报；PySide6 上位机绘制实时曲线，内置轻量 LSTM 或 Isolation Forest 模型，自动识别异常趋势并弹出预警。对标工业 SCADA 和物联网岗。

AI 在哪：PC 端 scikit-learn / PyTorch 训练异常检测模型，运行时推理在 PC 上位机
MQTT / paho PySide6 + pyqtgraph LSTM / Isolation Forest 传感器接口 物联网
03

人脸识别智能考勤 / 门禁系统

开发板摄像头识别人脸，PySide6 管理端查考勤记录

开发板运行 InsightFace（轻量版）完成人脸检测 + 特征提取，结果经 HTTP/WebSocket 推送到 PC 管理端；PySide6 提供人员注册、打卡记录查询、考勤报表导出功能，SQLite 本地存储。场景感强，学生容易演示。

AI 在哪：开发板端跑 InsightFace ONNX 模型，PC 端做管理 UI 和报表
InsightFace / ONNX PySide6 WebSocket / HTTP SQLite 嵌入式 AI
04

AI 语音交互智能助手（含大模型）

语音唤醒 → STT → 大模型 API → TTS → 屏幕显示

开发板麦克风采集音频，Whisper（tiny/base）做语音识别，文本发给 PC 端调用 DeepSeek / 通义千问 API，回答经 TTS 合成后送扬声器播放，同时 PySide6 界面显示对话内容和波形动画。非常适合展示，家长参观必惊艳。

AI 在哪：开发板 Whisper 离线 STT + PC 端大模型 API（DeepSeek/通义），全链路 AI
Whisper 大模型 API PySide6 TTS / pyttsx3 音频流处理
05

视觉引导机械臂 / 小车控制系统

摄像头识别目标坐标 → 上位机解算 → 串口控制执行器

开发板摄像头用 YOLOv8 或颜色分割识别目标位置，PC 上位机（PySide6）做坐标解算和轨迹规划，通过串口发送指令控制下位机（步进电机/舵机）；界面实时显示摄像头画面、目标框和运动状态。硬件感最强，招生效果最好。

AI 在哪：开发板视觉识别（ONNX 推理），PC 端运动规划 + 界面，可选 LLM 语音下令
YOLOv8 / OpenCV pyserial 串口 PySide6 运动控制 嵌入式 + 视觉
