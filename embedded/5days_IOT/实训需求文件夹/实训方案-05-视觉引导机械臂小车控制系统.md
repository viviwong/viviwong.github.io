# 视觉引导机械臂 / 小车控制系统

用心做教育，专注每一位学员的成长

---

## 项目名称

**视觉引导机械臂 / 小车控制系统**

---

## 1 项目开发背景

工业机器人与自动化设备正在深刻改变制造业。视觉引导抓取（Bin Picking）、AGV 无人车、分拣流水线等场景，都依赖"看 → 想 → 动"的完整感知-决策-执行链路。国内各大工厂的自动化升级带来了大量**机器视觉工程师**、**运动控制工程师**岗位需求，薪资水平处于嵌入式方向的高位段。

本项目以 S5P6818 开发板为视觉感知与上位机运算平台，通过摄像头识别目标位置，经坐标解算后通过串口下发运动指令，控制机械臂或小车完成视觉引导动作，帮助学员建立**从像素坐标到物理运动的完整工程思维**，直接对标机器视觉与运动控制工程师岗位。

---

## 2 项目开发目的

- 掌握 YOLOv8 目标检测模型在 ARM 平台的 ONNX 部署与推理
- 学会摄像头标定与像素坐标到物理坐标的转换（手眼标定）
- 掌握串口通信协议设计，实现上位机对下位机（舵机/步进电机）的精确控制
- 使用 PySide6 构建实时显示摄像头画面、目标框、运动轨迹的控制界面
- 理解运动规划基础（插值、速度曲线）
- （可选）接入 LLM 语音指令，实现"用说话控制机械臂"

**技术栈覆盖：**

| 技术方向 | 具体技术 |
| :--- | :--- |
| 目标检测 | YOLOv8n ONNX + ONNX Runtime ARM |
| 计算机视觉 | OpenCV（摄像头标定、坐标变换）|
| 运动控制 | pyserial 串口 + 自定义控制帧协议 |
| 桌面 UI | PySide6（实时画面 + 控制面板）|
| 可选扩展 | LLM API 语音下令（DeepSeek）|
| 开发平台 | S5P6818（Ubuntu）+ 下位机（STM32 / Arduino）|

---

## 3 项目简介

本系统以 S5P6818 开发板为核心，摄像头实时拍摄工作台画面 → YOLOv8 模型检测目标物体位置（返回边界框中心像素坐标）→ 经摄像头标定矩阵将像素坐标转换为物理坐标 → 生成末端执行器（机械臂爪 / 小车轮）运动指令 → 通过串口（UART）下发给下位机（STM32 / Arduino）→ 下位机驱动舵机或步进电机完成动作。PySide6 界面实时显示摄像头画面、目标检测框、当前坐标和运动状态。

## 6 项目实训成果

完成本实训后，学员能够独立完成：

- 在 ARM 开发板上部署 YOLOv8 ONNX 模型并进行实时推理
- 完成摄像头标定，建立像素坐标与物理坐标的映射关系
- 设计串口控制协议，控制舵机或步进电机完成指定动作
- 构建实时视觉引导控制的 PySide6 桌面应用

**系统架构图：**

```
┌─────────────────────────────────────────────────┐
│            S5P6818 开发板（感知 + 决策）          │
│  摄像头 → OpenCV 采集                            │
│  → YOLOv8 ONNX 推理 → 目标像素坐标              │
│  → 标定矩阵 → 物理坐标                          │
│  → 运动规划（插值/轨迹）→ 控制指令帧             │
│  → pyserial 串口发送                             │
│                                                  │
│  PySide6 界面（实时画面 + 目标框 + 状态面板）    │
└────────────────────┬────────────────────────────┘
                     │ UART 串口
┌────────────────────▼────────────────────────────┐
│         下位机（STM32 / Arduino）                 │
│  接收控制帧 → 解析角度/速度指令                  │
│  → 驱动舵机 / 步进电机 → 机械臂动作 / 小车运动  │
└─────────────────────────────────────────────────┘
```
