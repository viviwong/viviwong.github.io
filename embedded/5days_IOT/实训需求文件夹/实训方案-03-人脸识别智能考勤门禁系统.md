**人脸识别智能考勤 / 门禁系统**

## 1 项目开发背景

随着人工智能与计算机视觉技术的飞速发展，人脸识别已从实验室走向企业园区、校园、工厂门禁等实际场景。传统刷卡/指纹考勤系统存在可代打卡、设备易损、维护成本高等痛点。人脸识别考勤系统通过摄像头自动识别身份，无需任何接触，实现"刷脸即打卡"，已成为各大互联网公司、制造企业的标配方案。

本项目以 S5P6818 嵌入式开发板为核心硬件，在开发板上部署轻量级人脸识别模型（InsightFace ONNX），结合 PC 端 PySide6 管理界面，完整复现企业级考勤门禁系统的核心功能，使学员直接对标**嵌入式 AI 工程师**和**计算机视觉工程师**岗位。

## 2 项目开发目的

本实训使学员能够：

- 了解人脸识别技术在企业中的实际应用场景与就业前景

- 掌握 Python WebSocket / HTTP 接口设计，实现嵌入式端与 PC 端数据通信
- 使用 PySide6 构建包含数据库查询、报表导出的桌面管理端
- 理解 SQLite 数据库设计与 CRUD 操作

## 3 项目简介

本系统以 S5P6818 开发板为**边缘推理终端**，摄像头实时采集人脸画面，板端运行 InsightFace 轻量 ONNX 模型完成**人脸检测 + 特征向量提取**，特征向量通过 HTTP 接口推送至 PC 管理端；PC 管理端由 PySide6 构建，提供**人员注册、实时打卡识别、考勤记录查询、报表导出**四大功能模块，所有数据持久化至 SQLite 数据库。

系统支持 1:N 人脸检索（在注册库中找最相似人员），识别准确率高、响应速度快（板端推理约 5–10 fps），完整还原真实企业门禁考勤场景。
